## 1. North star（願望カタログ）

距離ラベル: **近い** / **中距離** / **遠い** / **工学**。  
遠い項目は **メタファー／要・操作定義**。各行の後半は「いまの物理との粗い対応」または「操作定義が先」。

| 距離 | 願望 | 粗い対応 / メモ |
|------|------|-----------------|
| 中距離 | 「細胞」を並べると脳波的なものを出すのか | 少数ネットの集団リズム・スペクトル。フル皮質ではない |
| 近い | さぼりが起きるのか | RQ1 の入力削り・代謝節約の延長 |
| 近い〜中 | タスクを解決できるのか | 既に玩具タスクあり；難易度・多条件は先 |
| 遠い | 細胞を殺すことでリハビリ的に肩代わりできるのか | **メタファー／要・操作定義**（細胞除去アブレーション→再割当） |
| 遠い | 自律的に回復や再構成が起きるのか | **メタファー／要・操作定義**（損傷後の再配線・ホメオスタシス） |
| 工学 | 式の組み込みで高速化できるか | 数値・JIT・随伴・スキーム最適化 |
| 中距離 | 配列パターン等で一つのモデルが複数タスクを解けるか | 共有物理 + 文脈／刺激パターン条件付け |
| 中距離 | 外挿性にとても強いのか | OOD ベンチが先；物理帰納バイアスの仮説 |
| 遠い | 無知を自覚できるか | **メタファー／要・操作定義**（不確実性・棄却・低信頼出力） |
| 中距離 | 時間感覚をもてるか | RQ2 の遅い痕跡は原始的入口；主観時間と同一視しない |
| 遠い | 夢を見れるか | **メタファー／要・操作定義**（オフライン再活性化等の定義が先） |
| 中距離 | 環境適応できるか | パラメータ／供給環境の変化への再適合 |
| 遠い | 飽きが出るか | **メタファー／要・操作定義**（新規性・習慣化の測度が先） |
| 遠い | ひらめき（相転移・トンネル）が起きるか | **メタファー／要・操作定義**；力学の相転移≠認知のひらめき |

## 2. 既に出ている予兆との対応（短く）

- **RQ1:** 選択・節約（さぼり／入力削り）の入口
- **RQ2:** 時間痕跡（時間感覚のごく原始的入口、ただし同一視しない）
- **RQ3:** 供給↓で弱い応答から消える（粗視化・優先の入口；ゲート依存）

これらは North star の**入口**であり、上表の遠い項目が示されたことにはならない。
